# Changelog

All notable changes to IAQ Security Patrol are documented here.

## 0.4.1 — GitHub public release

- Prepared the project for a public GitHub repository.
- Added WordPress plugin compatibility and license metadata.
- Added README, security policy, contribution guide, changelog, and repository ignore rules.
- Updated the plugin HTTP User-Agent version to match the release.
- No patrol, detection, crawler-verification, logging, or banning logic was intentionally changed.

## 0.4.0

- Added exploit-probe and sensitive-file detection.
- Added behavioral burst, sustained-scraping, and direct URL enumeration detection.
- Added temporary bans and admin event views.
- Added Cloudflare-aware client IP handling.
- Added verification logic for selected legitimate crawler families.
